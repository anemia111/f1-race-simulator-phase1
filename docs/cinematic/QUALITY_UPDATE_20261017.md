# 鈴鹿 Cinematic 品質改善 — 2026-10-17

前回の公開版（fbbe624）から、植生、バリア、メインストレート施設の細部、車輪の描画を改善した。フォトリアルPhase 1の完成判定は引き続き未達。レースエンジン・Worker・既存データ・サービスに差分はない。

## 変更内容

- 楕円状の樹冠を、枝と透過葉を持つ生成樹木へ置換。広葉樹2種・針葉樹1種の形状を用いるが、鈴鹿の樹種調査に基づくものではない。
- EZ-Tree 1.1.0（Daniel Greenheck、MIT）の生成コードと同梱葉テクスチャを利用。MIT全文、葉テクスチャのライセンス宣言への参照、元ファイルと生成ファイルのSHA-256を保存。ブラウザに生成ライブラリを読み込まず、事前生成したMeshopt GLBとテクスチャを配信する。
- LOD0は枝葉の立体、LOD1は同じ枝構造と軽量な葉群、LOD2はLOD0から焼き出した512px透過画像をカメラへ向けるインポスター。LOD2は1本2triangle。高精細な立体の表示数に上限を設けた。
- 最大700本の母集団を固定seedで生成。品質を変えても先頭の樹木位置は変わらない。中心線の全道路枝を調べ、別の道路や立体交差の下側へ木が入り込む配置を除外する。
- メインストレートの黒い張り出しフェンス支柱は既存のライセンス確認済み実写を参照。外周は独自制作の波形鋼製ガードレールへ分離。フェンス網は大きな菱形から細かい格子へ変更した。
- ピット建物の窓枠、水平帯、庇、スタンドの屋根支持・手すりを追加。写真からの視覚推定であり、寸法・配置を測量値とは扱わない。
- 車輪スポークとブレーキディスクを車輪の回転・操舵階層へ接続。前版で車輪の外にあった静止スポークを修正した。シミュレーションの速度・順位・状態は変更しない。

## 確認と制約

ビルド、Lint、9ファイル37テスト、アセット整合性とGLB実デコードを確認した。新しいテストは品質間の配置安定性、両方の道路枝との離隔、近距離モデル数の予算を検証する。

最初の樹木試作では葉の間引きと描画負荷の両方が問題になったため、遠距離インポスターと中距離葉群の専用生成を導入した。中間試作の測定値は最終性能と混同しない。最終結果の正本は `suzuka-quality-release-qa/results.json`。

計測はIntel Iris Xe / D3D11で、各条件約1秒の窓を10個収集する短時間走行。内部解像度は品質によって異なる。同じラップ距離・同じフレームへ固定した比較ではなく、前版に対する性能向上率は算出していない。安定60fps、全周のカメラ非干渉、2時間耐久、VRAM実測の合格を意味しない。

樹木は汎用の生成形状であり、鈴鹿の樹種・樹高・位置の実測再現ではない。遠距離インポスターは1方向の形状・中立照明を焼き出したもので、見る方向・動的な光との整合性に限界があり、近距離・空撮では立体LODを使う設計の改善余地がある。風、枝の揺れ、葉の透過光、樹皮PBR、LOD間のフェードは未実装。

施設の位置・寸法、局所幅、バンク、縁石、ピット経路、周辺地形の実測不足、正式チーム車体・リバリー、詳細コックピット、雨粒・水しぶき、KTX2、長時間試験は未完了。今回の変更でこれらを解決済みとは扱わない。

## 再現

```powershell
npm ci
npm run generate:cinematic-vegetation
npm run validate:cinematic-assets
npm run build
$env:CINEMATIC_HARDWARE='1'
npm run playtest:cinematic
```

生成樹木の枝構造は固定seed。インポスター画像のピクセルはブラウザ・GPU・Three.jsの描画実装によって差が生じ得る。通常の起動は同梱済みのアセットを使い、生成や外部画像取得は行わない。

## 公開確認

更新版を https://anemia111.github.io/?release=b265175 に公開した。デプロイコミット b265175、releaseId 20261016T152530Z（UTC表記）。公開手順のLint・build・既存ブラウザplaytestは成功。全体Vitestは前回確認した失敗を未解決のまま省略しており、全suite合格とは扱わない。

公開側で15アセット（合計7,297,768 bytes）のSHA-256・byte数をローカルmanifestと照合し、すべて一致した。鈴鹿Onboardの表示とOverview Mapへの復帰を確認。JavaScriptエラー0、公開ファイルの取得失敗0。公開動作確認は1280×720のソフトウェア描画であり、実GPU性能測定とは別の証拠である。

最終実GPU測定は公開用distを使用し、公開手順の重いブラウザ試験終了後に行った。22台High Chaseは55.82fps／平均GPU13.36ms、40台High Chaseは55.80fps／平均GPU16.58ms。60fps受入は未達。新しい品質を保ちながらGPU時間とフレーム間隔の余裕を作る作業が必要。

比較HTMLは4画像のロードとスライダー動作をブラウザで確認した。新しい描画対象のテストは9ファイル37件成功、植生GLBは構造errors 0・warnings 0、12ノードのMeshopt実デコードを確認した。実写との画角較正・フォトリアル完成・長時間安定性の合格は主張しない。
