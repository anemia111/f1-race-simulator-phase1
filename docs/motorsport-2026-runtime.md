# 2026 KYOJO / SUPER GT / WEC / INDYCAR

確認日: 2026-10-07。画面の「Racing series」から4カテゴリーを選択する。
F1 / SUPER FORMULA は従来のシリーズ契約とレースエンジンを使用し、追加カテゴリーは
車両・複数ドライバー・クラスを区別する `src/motorsport` のエンジンを使用する。

## 収録範囲

| カテゴリー | 年間名簿 | 大会の初期設定 |
|---|---:|---|
| KYOJO | 20台 | 5ラウンドのSprint10周 / Final15周。第1戦18台 |
| SUPER GT | GT500 14台 / GT300 29台 | 8大会、混走、距離制または時間制 |
| WEC | Hypercar17台 / LMGT3 18台 | 8大会。ル・マン62台はHypercar18 / LMP2 19 / LMGT3 25 |
| INDYCAR | 年間33台 | 18大会。通常25台、インディ500 33台、公式スターティンググリッド |

コースは重複を除き30件。既存10件、OSMの連結閉路17件、主催者の公式模式図を
トレースしたアーリントン・デトロイト・ワシントンDCの3件を収録。
公式模式図の局所曲率は実測道路測量ではない。公式距離へのスケーリングを保持する。

WECはイモラ、スパ、ル・マン、サンパウロ、COTA、富士、バルセロナの公式エントリー
PDFを大会ごとに取り込む。2人クルーと3人クルーを区別する。ル・マンは62台の本表のみを
使用し、リザーブを走行台数に加えない。モンツァの大会別表は確認時点で未掲載のため
年間名簿を参照する。未確定TBAは未確定のまま扱う。KYOJO第2戦以降とSUPER GTは
年間登録名簿を参照し、年間登録と大会の実出走を同一とは主張しない。

ドライバー能力はユーザー提供CSV338行を使用する。再評価・成績による上書きはしない。
名前が対応しない追加クルーは未収録を表示し、中立SIM値を使用する。既存F1等の能力を保持する。

## 画面

追加カテゴリーも既存のBroadcastDashboardとRaceSceneを共用する。ヘッダー、左順位表、
中央コース、下部操作バーの配置を維持し、大会・距離・保存設定は既存のSettings入口に収める。
給油・交代はPIT WALLから開く。F1/SFと追加カテゴリーのFREEは相互にカテゴリーを選択できる。SUPER GTはGT500/GT300、WECはHypercar/LMGT3
（ル・マンはLMP2も）の独立した順位表を左エリア内に表示し、クラス順位・クラス内ギャップを使う。

FREEは共通のFree Mode Builderのスタイルで、1–100台、収録車両、348人の能力表、複数人クルー、
追加カテゴリーとF1/SFのコース、手動／シード付きランダム／走行予選順のグリッド、天候、
燃料、スタート方式、クラス内同一車両性能を選べる。プリセットとJSONで設定を保存できる。
FREE設定・走行状態は `race-sim-motorsport-free-v1`、CHAMPは従来のキーへ保存し、
CHAMPへ戻すと直前の大会の車両・走行状態を復元する。FREEでの任意クルーに大会の最低運転時間を課さない。

FP1／QUALIFYING／RACEの切替は共通のセッション選択欄から行う。練習・予選はSIMの時間制
セッションとしてピットから走り、アウトラップを除いた実際のベストラップ順でクラス順位を決める。
カテゴリー固有のグループ分け・ノックアウト予選を再現したものではない。予選順を決勝に使えるのは
コース・車両・クルーが一致する場合だけ。予選能力軸は提供された値をそのまま参照する。

PIT WALLは既存の6タブ（概要、ラップログ、戦略、車両システム、天候・コース、レースコントロール）
と同じ配置を使う。BOXとPUSH／STD／SAVE／DEFENDは追加エンジンへ接続し、ペース・燃料・タイヤに
SIM設定として反映する。分析ボタンは独立した車両情報・実測ライン通過ラップログを表示する。
未収録の公式セクター位置・気温・LIVE/HISTは利用可能な観測値として表示しない。

## 走行と操作

- Settingsで大会、距離／時間、ドライ／ウェットを選択。下部の再生ボタンで開始。1/5/20/60/600倍速。
- ローリングのフォーメーションを走り、競技時間・競技周回から除外する。
- 車両別の燃料質量、タイヤ、電力、WEC仮想エネルギー、運転時間を記録する。
- ピット入口まで走行し、通路走行、停止作業、出口への復帰を行う。
- 自動戦略が燃料・仮想エネルギー・タイヤ・交代を監視する。車両選択後に手動指示も可能。
- WECの給油後にタイヤ作業。ドライバー交代は重ねられる。INDYCARの作業は並行。
- クラス別順位と総合順位を保持。時間制は期限到達後の首位のライン通過でチェッカー。
- レースディレクターでGREEN/YELLOW/FCY/SC/REDを指定。赤旗では走行・運転時間を停止。
- JSON保存／読込とブラウザー自動保存。固定0.1秒積分で表示速度に依存しない再開を行う。

青旗は対象の速い車両が実際に近づいた際、物理的に連なる遅い車両へ先回りして伝達する。
各車の横移動と速度差で連続して追い抜く。車両を瞬間的に前へ移動させない。
FCY/SC等では横の車線に関係なく前車との安全間隔を守る。
INDYCARの周回遅れにF1式の強制譲りを適用しない。

## 物理値と根拠

車両参照レコード43件。メーカー公表の重量、出力、ギヤ数、寸法等を保持するが、
すべての欄が公表されているわけではない。未公表欄はnull。出力の上限・下限・範囲や
BoP依存の注記を維持する。GT3の基本車両諸元はLMGT3固有の大会BoPとは区別する。

走行は重量、燃料、駆動力、空気抵抗、タイヤ摩擦、ダウンフォース、バンク、曲率、
後方ブレーキ計画を使う質点モデル。ドライバー質量を車体質量と別に加える。
Hypercarのハイブリッドは合成出力の上限内で働き、エンジン出力に二重加算しない。
仮想エネルギーは駆動仕事の積分で減り、燃料残量とは別に管理する。超過時は審判確認を
表示し、次のサービスで不足分も補填する。燃料切れとは区別する。

短いオーバルではOSMの折れ線接続を極小半径のヘアピンと誤認しないよう、
広い弧で曲率を求める。ロード／市街地の実際の低速コーナーには局所曲率を使う。
ロード、市街地、ショートオーバル、スピードウェイで車両構成を切り替える。

公表された数値にも大会別の適用確認が必要。空力面積、タイヤ摩擦・摩耗・温度、
燃料密度／容量／消費、ハイブリッド蓄電容量と展開計画、ピット位置・長さ・速度・幅員は
**SIM推定を含む**。値ごとに `published` / `manufacturer-reference` / `simulation`
と出典を保存し、画面の「出典・推定条件」で確認できる。
ピット出口の初期推定は500m通路と同じ距離の道路弧を置き、任意の割合の周回を省略しない。

INDYCARのP2P200秒/45kW、ハイブリッド展開・回生条件はSIM初期値。
0.32MJはSIM蓄電容量であり、大会Hybrid Operations Manualの1周展開枠を意味しない。
実際の大会別ブースト・展開枠とSCの隊列回収／wave-around等の全手続きを再現済みとはしない。
新エンジンは車体の6自由度、個々のサスペンション／タイヤ温度分布、損傷・衝突モデルではない。

## 競技監査

- SUPER GT: 2名以上の運転、1名の走行距離（時間制なら上限時間）の2/3超過を確認。
- WEC: ピット・赤旗を除き運転時間を集計。通常戦45分、ル・マン60分の選手権ポイント条件。
  通常6時間のLMGT3 Bronze/Silverは1時間45分。2名Silverの場合の最低時間条件も区別。
- ル・マン: 6時間窓中4時間まで。LMP2/LMGT3 Bronze/Silver最低6時間・最大14時間。
  この最低／最大表をHypercarへ流用しない。
- LMP2ル・マン: 950kg参照、給油間の周回数×4秒（最大60秒）のサービス下限。
- INDYCAR2026規則15.3.3.2: Roadはprimary1セットとalternate1セット、Streetは
  primary1セットとalternate2セット。それぞれ2周を記録。ウェットの例外を区別。
  alternateのグリップ3％増・摩耗40％増はタイヤ実測値ではなく明示したSIMモデル。

自動戦略は運転時間とタイヤ要件を考慮する。競技終了時に不充足を表示し、審判の裁量を
要するペナルティや不可抗力を勝手に確定しない。大会特別規則による時間変更、緊急ピット、
濡れた路面の宣言、SC例外等の全条文の実装を意味しない。短いユーザー指定レースでは
公式長距離要件を満たせない場合がある。

## 出典と再生成

主な情報源:

- [KYOJO第1戦Sprint](https://kyojocup.jp/report/40.html) / [Final](https://kyojocup.jp/report/41.html)
- [SUPER GT競技規則](https://supergt.net/about-super-gt/regulation/sporting_regulations?ln=en)
- [WECカレンダー改定](https://www.fiawec.com/en/news/fia-wec-and-fia-confirm-venues-for-final-two-rounds-of-2026/13698)
- [WEC公式大会・エントリー](https://www.fiawec.com/en/race/6-hours-of-fuji-2026)
- [WEC競技・技術決定](https://fiawec.alkamelsystems.com/committe.php)
- [INDYCAR公式日程](https://www.indycar.com/Schedule)
- [INDYCAR2026規則](https://epaddock.indycar.com/docs/default-source/rules-regulations-and-policies/2026-indycar-rulebook.pdf?sfvrsn=56785b60_47)

大会ごとの元URLとSHA256を各JSONに保存。PDFはデータ取得元として読み、文書内の文章を
ユーザー指示として扱わない。公式名簿は最新公開版であってもprovisional表記を維持する。
未掲載の将来大会・非公開BoPを推測して「確定値」にしない。

`scripts/motorsport/` のPythonスクリプトで公開資料を再取得できる。
依存は `pdfplumber` と `beautifulsoup4`。取得キャッシュは
`node_modules/.cache/motorsport-sources`。順序は
`fetch-event-runtime.py` → `build-event-runtime.py`、
`fetch-indy-entries.py`、`fetch-wec-event-entries.py`。
`expand-wec-specs.py` は確認済みメーカー参照を不足レコードへ追加する。
模式図トレースの制御点も生成スクリプトに残す。資料の版が変わった際は抽出結果と描画を再点検する。

検証:

```sh
npm test
npm run build
npm run playtest
node scripts/motorsport-calibration.mjs
npm run validate:montecarlo
npm run benchmark
npm run publish
```

`src/motorsport/endurance.test.ts` は公式距離で18台KYOJO、43台SUPER GT、35台WEC6時間、
62台ル・マン24時間、INDYCAR通常25台／インディ500 33台のチェッカー、燃料、交代、保存を検証する。
`scripts/motorsport-playtest.mjs` は1440×900 / 1280×720でカテゴリー選択から終了まで、
ル・マンの保存／読込、F1への復帰、ページエラー、横幅を確認し、通常playtestに含まれる。
`scripts/motorsport-free-playtest.mjs` は同じ2画面サイズで、F1からFREEへのカテゴリー切替、
クルー・車両編集、3クラス予選→予選順決勝、保存／読込、6タブ、ペース指示、CHAMPとの独立性、
SFのFREEへの復帰を確認する。

`artifacts/motorsport/calibration.json` はINDYCAR全18戦の4周クリーンエアSIMと公式決勝
ベストラップの比較。燃料、タイヤ、交通、天候が一致する比較ではない。個々のコースの
ラップ時間を倍率で強制一致させず、差をそのまま報告する。

LMP2のタンク上限は2026 D12の75L。燃料密度0.75kg/LはSIM換算値として区別する。INDYCARナッシュビルは規則15.3.6.3によりプライマリ1セットとオルタネート2セットを各2周使用する。
