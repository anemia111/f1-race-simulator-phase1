# F2ドライバー能力評価・反映の精査（2026年10月13日）

対象は公式2026年F2ランキングに記載された23人。現在のアプリではF2は独立した走行カテゴリーではなく、各選手を既存6カテゴリーへ起用する共通ドライバープールの評価を見直した。

**能力点はSIM上の編集評価で、公式評価ではない。** 2026年の成績と各人の過去実績を併せて判断し、順位やポイントから機械的に換算していない。F1の最上位95–98、SF主力83–87という既存の共通尺度を維持。普通のドライバーは最大100、Yuki Nakayamaだけ120。

## 根拠と評価範囲

- [2026年F2公式ランキング](https://www.fiaformula2.com/en/standings/2026/drivers)：確認時点ではバクーまで。シーズン最終結果ではない。
- [2026年F2公式選手紹介](https://www.fiaformula2.com/en/drivers)：各プロフィールの2025年以前の成績も参照。
- ランキングは車両・チーム・トラブル・欠場・リバースグリッド等の影響を含む。車両差を分離した予選・決勝ペースの推定は行っていない。
- ハータは2024年INDYCAR2位・2025年6位、宮田は2023年SFとGT500の両タイトル、バローネは2023年WEC LMGTE Am王者の実績も考慮。F2順位だけで大幅に下げない。
- 山越はF2デビューの小標本を順位だけで減点せず、2026年F3での9位も参照。
- 30項目へ展開する相対的な能力配分は、従来の未計測SIM推定を維持。総合値の改定分を共通オフセットで反映する。雨、タイヤ管理、ブレーキ等を個別に実測した評価とは扱わない。

## 人物の区別と旧データ

現行F2のEmerson Fittipaldi Jr.は`expansion_emerson_fittipaldi_jr`、旧履歴のEnzo Fittipaldiは`enzo_fittipaldi`として分離。旧F2履歴のエンツォをエマーソンへ書き換えたり、旧歴史資料を現在のラインアップと誤表示したりしない。バクーでの山越起用も人物を上書きせず別IDのまま保持する。選手の評価対象にF2を追加しても走行カテゴリーは追加されない。

## 保存データと走行計算

共通プールからF1/SFへ起用すると、改定後の12項目から30項目を展開。KYOJO/GT/WEC/INDYCARも同じ人物の能力を行動・ペダル・グリップ計算に渡す。

修正した問題：細分化能力を持つ追加4カテゴリーの保存データは、以前は旧初期値でも評価更新の対象外になっていた。現在は総合値・簡略能力・30項目全体が既知の旧初期値と一致した場合に更新する。1項目でも編集があればそのプロファイルを保持。ネイティブのF1/SF保存値も今回改定前のスナップショットと照合して更新する。旧F2履歴の合成初期値も明示的に照合対象へ加えた。

セットアップと既存のレース結果は保持。将来性は現在能力を下回らないようにするが、低下した現在評価に合わせて既存の将来性を下げない。

96件の短いテスト（7スイート）が通過。23人の人物ID・上限・共通評価、F1/SFの起用と旧保存値、追加4カテゴリーの簡略/詳細保存値と実保存ファイル、手動変更保持、全カテゴリーの実際の力計算への能力入力、および設定・ネイティブ/追加カテゴリー保存の回帰確認を含む。全レースの順位再現や長時間テストは行っていない。
