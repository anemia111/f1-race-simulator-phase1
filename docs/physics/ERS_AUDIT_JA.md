# ERS・走行挙動改修：実装と検証記録

> 続行作業で通常走行の力積分距離→位置更新を接続し、Cinematicの停止・再開表示を修正した。
> 本資料は最初のERS改修時点の記録。最新状況は `STUTTER_FIX_20261017_JA.md` を参照。

確認日：2026-10-17。比較元：`0ae1525795996f781fa52d313616989d633b26ba`。
今回のコードはローカル版。公開サイトの既存リリースへは反映していない。
ユーザーの最新指示に従い、以前の「エンジンを変更しない」制約を、この物理改修について解除した。

## 達成範囲

Phase Aの出力経路の不具合修正、制御実験、診断表示を実装した。Phase C/Dの明確な不具合も限定的に修正した。
全Phaseの完成、実車相当の物理精度、長時間フルレースの安定性は未達成。
本資料の数値はシミュレーションの実行結果であり、実車の測定値ではない。

## 1. 監査で確認した事実

| 経路 | 確認内容 | 判定 |
|---|---|---|
| energySystem → drivetrain → vehicleDynamics | Energy Storeが受け付けた機械出力を、ICEと合算した後に再度アクセル開度で縮小 | 修正 |
| energySystemの時間集計 | 既に内部スライスの電力を時間平均している。最終スライスだけを使用する実装ではなかった | 維持 |
| DC → インバーター → MGU-K | 変換損失・SOC・温度・蓄電残量を扱う既存台帳あり | 維持・制限値の記録追加 |
| drivetrain | F1駆動側のクランク軸換算500 Nm上限がなかった | 修正 |
| activeAero / telemetry | 追加0.5 MJ回生枠をOvertake専用の放電残量として利用 | 使用許可とDC出力の誤った制限を除去 |
| following | 同速・目標車間の状態で要求減速度0なのにアクセル倍率0 | 修正 |
| overtaking / race | 確率上のクリーンパスが相手の時間損失を発生させ、物理的な前後関係に介入 | ライブのクリーンパス時間補正を除去 |
| race順位・イベント | 積算位置の前後関係の変化を検出する処理は既存 | 維持 |
| side-by-side | 秒単位のギャップのみで並走と表示する経路 | 車体前後の包絡重なりと横方向距離へ変更 |
| physicalLap / trackDynamics | 曲率、速度プロファイル、進入・APEX・脱出の参考オフセットを既に生成 | 維持。ただし連続コーナーの候補軌跡最適化は未実装 |
| lateralDynamics | メートル単位の横位置・横速度、有限速度・加速度、車体占有判定あり | 維持 |
| tyreForces | 荷重感度、縦横のグリップ配分、ダウンフォース・荷重移動あり | 維持 |
| Tow / Dirty Air | 既に抵抗・ダウンフォースに作用。横ずれと秒単位車間を使用 | 維持。ただし実距離・速度を使うウェイク校正は未完了 |
| driverDecision / categoryDriverAgent | ブレーキング精度、攻撃・防御、リスク、エネルギー意図を既に使用 | 維持。能力値・編集データは変更していない |
| race移動距離 | 力積分の終端速度から距離を進め、交通・黄旗・SC等がさらに制約。力積分での距離と一致しない場合あり | 差を診断可能にした。統一は未完了 |
| Worker | 50 msの物理サブステップと速度別送信間隔を既に分離 | 維持。2台・3秒のバッチ整合性を追加検証 |

`FORMULA_VEHICLE_LENGTH_M=5.2` は占有判定用の推定包絡であり、全車の実測全長ではない。
古い `overtakeForLap` は互換性と既存の統計試験のため残す。ライブは新しい
`physicalBattleIncidentForLap` を通し、接触・クラッシュだけを受け取る。
接触リスクは依然としてシード付き推定モデルであり、衝突剛体計算に置き換わったわけではない。

## 2. ERS不具合の再現と修正

初速250 km/h、ICE出力0、受け付け済みMGU-K機械出力200 kW、アクセル60%、駆動効率0.94、非トラクション制限という条件で再現した。

- 変更前：車輪側112.8 kW = 200 × 0.94 × 0.60。
- 変更後：車輪側188.0 kW = 200 × 0.94。
- アクセル100%：変更前後とも188.0 kW。

アクセルはICE側へ適用し、既にエネルギー系が許可したMGU-K出力には再適用しない。
ドライバーの電力要求自体は従来どおりエネルギー意図とペダル状態から生成する。
架空の速度加算、最高速度の引き上げ、ドライバー能力値の変更は行っていない。

## 3. A〜D制御実験

`scripts/validate-ers-coupling.mjs` が本番の energySystem、drivetrain、vehicleDynamics を使用する。
燃料30 kg、初速180 km/h、SOC90%、一定グリップ、平坦路、8秒、50 ms刻み。
電力要求A=0、B=25%、C=60%、D=100%。通常DC出力カーブ、温度、SOC、ギア、タイヤ、空気抵抗を有効にした。
AIの使い所判断を分離するため、要求を実験側から直接入力している。フルレースや観測テレメトリーではない。

### ICEアクセル60%：変更前 → 変更後

| 条件 | 8秒後車速 km/h | 8秒走行距離 m | 400 m到達 s |
|---|---:|---:|---:|
| A なし | 215.950 → 215.950 | 448.921 → 448.921 | 7.181 → 7.181 |
| B 低 | 234.514 → 245.909 | 473.395 → 489.024 | 6.863 → 6.681 |
| C 中 | 257.390 → 280.442 | 505.404 → 538.621 | 6.504 → 6.182 |
| D 高 | 277.740 → 308.269 | 538.255 → 587.140 | 6.182 → 5.773 |

Dでは同じ8秒間の距離が48.885 m増え、400 m到達が0.409秒早まった。
これは独立した制御走行の比較であり、2台のバトルで測ったギャップではない。
変更後Dの蓄電池からの取り出しは2.713 MJ、最終SOC22.17%。
変更前Dは2.768 MJ。車速が変わることで速度依存出力カーブも変わるため、8秒全体で消費量は同一ではない。

ICEアクセル100%では、A〜Dすべての終端速度・距離・到達時間が比較元と一致した。
変更後の終端速度はA297.104、B314.961、C331.072、D341.581 km/h。
高速域の規則制限は有効であり、電力要求に比例して無制限に速度が上がるモデルではない。

低速20 km/h・グリップ0.55・2秒のトラクション支配ケースも別途記録した。
これは直接要求による接地モデルの診断であり、50 km/h未満の実レースのMGU-K発進許可条件を再現する試験ではない。

成果物：`ers-experiment-before.json`、`ers-experiment-after.json`、`ers-timeseries.csv`、
`ers-comparison-summary.csv`、`ers-before-after.png`、各条件の6面グラフ。
比較元には診断ハーネスのみをコピーし、エンジンソースは変更していない。

## 4. 2026年規則の確認

確認した一次資料は [FIA公式一覧](https://www.fia.com/regulation/category/110)、
[Technical C20](https://www.fia.com/system/files/documents/fia_2026_f1_regulations_-_section_c_technical_-_iss_20_-_2026-08-05.pdf)、
[Sporting B09](https://www.fia.com/system/files/documents/fia_2026_f1_regulations_-_section_b_sporting_-_iss_09_-_2026-10-01.pdf)。
C5.2 / B7.2のエネルギー関連を再確認した。

DC最大350 kW、SOC使用窓4 MJ、速度依存の通常／Overtakeカーブは既存実装を維持。
C5.2.11のクランク軸換算500 NmをF1の駆動側に追加した。回生トルクは既存の車輪側換算を使用しており、クランク軸上限との統合は残課題。
C5.2.10(iii)の最大0.5 MJは追加回生であり、Overtakeの放電専用枠と解釈していた制限を除いた。
検知地点・活性化周回・Race Control・低グリップ・SOCの既存ゲートは維持した。
Car Insights / Pit Wallも古い「Overtake専用残量」の表示をやめ、周回にラッチされた実際の追加回生枠を表示する。
古いセーブ互換フィールドは残すが、ライブの使用許可・DC制限・観戦画面には用いない。

`regulations.ts.energyAudit` に今回確認した版と範囲を記録した。
非エネルギー系が使う凍結済みB08/F10のメタデータは保持している。
Operational F11、Driving Standards、全Sporting条項を全面移行したとの主張はしない。

**未完了**：Boostの独立した操作状態、加速区間別のイベント条件の全面実装、
追加回生のControl Line条件の精査、非公開FIA-F1-DOC-058/111の値の再現。
既存SOC24%ゲートはシミュレーター方針であり公式の固定SOC閾値ではない。
不明なイベント条件を公式実測値として補ってはいない。

OverviewとCinematicの `Physics` ボタンから、選択車両のSIM診断を開ける。
速度・加速度・質量・アクセル／ブレーキ、力、縦方向グリップ限界、抗力、荷重、
MGU-K要求・許可DC・実DC・SOC、ハードウェア／温度／SOC／残量上限を表示。
エネルギー系の受け付け済み機械出力と、最終回転数でのMGU-Kトルク・機械出力を分ける。
参考ラインと実横位置、横速度、Tow、Dirty Air、AIの選択候補も表示する。

エネルギー出力はフレーム平均、制限値は最終内部スライス、力は力積分末尾。
力積分距離と交通処理後の解決距離を併記する。
ヨー角速度・ステアリングは現状の物理状態にないため、測定値として表示しない。
HIST/LIVEにSIMの物理値を混ぜない。

## 7. 未解決の物理上の制約

1. モーターのトルク／回転数制限や接地力のクリップ後に、エネルギー系へ需要を戻す同時解法が未実装。
   エネルギー台帳の残差0だけでは、車両全体のエネルギー閉鎖を証明できない。
2. 位置更新は依然として終端速度ベース。力積分距離を一貫して位置・交通・ラップ跨ぎへ結合する改修が必要。
3. 参考ラインは局所曲率からの推定。実際の中心線データは走行軌跡由来もあり、幅方向へ二重に拡げない監査が必要。
4. ウェイクは秒単位の車間を主に使う推定。距離・速度・車幅に基づく校正と2台長時間比較が必要。
5. クリーンパスの確率時間補正は外したが、クロスラインやAPEX権利・防御の制約が完成したわけではない。
6. バトル接触と車両停止・事故・SCには既存の推定・運用制約が残る。純粋な剛体衝突モデルではない。
7. 描画車体ヨー／ステアリングは参考線に基づく演出。横運動との完全な姿勢整合は未完了。
8. 不具合修正で部分アクセルの実出力が変わったため、従来のラップ・摩耗・戦略校正を再検証する必要がある。
   観測値へ合わせるために架空の速度補正を足す対応は行っていない。

## 8. 性能と映像の判定

今回のベンチマークは1920×1080のウィンドウ、Overview Map、22台とFree40台。
使用GPU表記はSwiftShader（ソフトウェアレンダリング）。最終測定は全体テスト停止後に実行した。
比較用に、全体テストを同時実行した負荷あり測定も別JSONとして保存した。
JSヒープはGPUメモリではない。画面FPSと実際に達成するシミュレーション倍率を分けて記録する。
60倍ボタンを押せたことを、実時間で60倍の処理速度を達成した証拠にしない。
Cinematicを含む全設定の実GPU60fps合格、GPU負荷・GPUメモリの測定は未達成。

60倍指定、SIM診断表示あり、各約8秒の測定結果：

| フィールド | 画面FPS | 実際の物理進行倍率 | 50 ms刻みから推定した物理更新/実秒 | 最長メインスレッド処理 |
|---|---:|---:|---:|---:|
| F1 22台 | 59.25 | 25.45倍 | 508.96 | 51 ms |
| Free 40台 | 55.76 | 9.73倍 | 194.60 | 76 ms |

物理進行は送信済み診断スナップショットのシミュレーション時刻差から算出する。
Worker内の各呼出しを直接計時した値ではなく、送信境界による誤差がある。
JSヒープ表示は35.57 MiB。40台の長時間メモリ安定性を示す測定ではない。
負荷あり測定では22台55.27fps・10.46倍、40台53.02fps・4.87倍だった。

TV画角は柵による遮蔽が残る。Onboardを含む写真／実映像との画角一致比較や、
鈴鹿S字・ヘアピン・130R・シケインの軌跡比較は未実施。
スクリーンショットは動作確認の証拠であり、フォトリアル品質の合格証明ではない。

## 9. 続行する実装順序と完成判定

| 段階 | 次の具体的な作業 | 合格条件 |
|---|---|---|
| A残課題 | 電力・モータートルク・接地力の需要返却、距離積分の統一、Boost/イベント条件 | 電池から車体まで仕事量が閉じ、刻み変更でギャップが収束 |
| B | 実寸道路座標を監査し、複数コーナーの候補軌跡に前進・後退速度解法を適用 | S字・ヘアピン・130R・シケインで連続した線・速度・車体姿勢 |
| C | 実距離と横ずれからウェイク評価、追従の制動距離・反応を校正 | 同性能2台で安定接近、急停止せず追従、ドライ／雨比較 |
| D | 攻撃・防御・APEX・出口の軌跡評価とコミット状態 | 直線／イン／アウト／クロス／撤退が物理位置から成立 |
| E | 能力・摩耗・温度・水量に応じた候補軌跡と操作 | 同条件の能力差・タイヤ差・雨量差を再現テストで説明 |
| F | 実横速度を反映する姿勢、イベントに基づくカメラ、観測比較 | 実映像との同地点比較、22/40台・全速度・長時間安定性 |
