中山裕樹のカスタムプロフィール（120点・#31）は出走枠を持たないプールに保持。
これは公式リザーブ契約の主張ではない。角田も通常の出走枠から外した。
能力値、マシン性能、シミュレーションの計算コードは今回変更していない。

保存済みの旧標準22席は、全員のID・所属・番号が旧標準と一致する場合だけ移行する。
継続して出走するドライバーの能力編集、チーム設定、ルール、カレンダーを保持する。
独自に組んだラインアップとインポートしたバックアップは自動で書き換えない。
過去レース結果を実在メンバーの結果として作り替える処理は行わない。
